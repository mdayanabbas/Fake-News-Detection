# YouTube Shorts Generator

A web application that generates high-quality YouTube shorts based on user-selected niches.

## Features
- Select from popular YouTube shorts niches
- Generate 5 high-quality videos per request
- 9:16 aspect ratio for YouTube shorts
- Automated audio and video generation
- Free tools and APIs integration

## Tech Stack
- Frontend: React with Tailwind CSS
- Backend: FastAPI with Python
- Database: MongoDB
